# GoToProd Claude Code plugins

Claude Code plugins from [GoToProd](https://github.com/GoToProd-dev).

## Plugins

| Plugin | What it does |
| --- | --- |
| [hcloud-cli](plugins/hcloud-cli) | Lets Claude manage Hetzner Cloud with the `hcloud` CLI. Unofficial, not affiliated with Hetzner. |

## Install

```shell
claude plugin marketplace add GoToProd-dev/claude-plugins
claude plugin install hcloud-cli@gotoprod-tools
```
